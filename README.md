# 🌤 Telegram Weather Bot

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue?logo=python&logoColor=white)](https://www.python.org/)
[![Telegram Bot API](https://img.shields.io/badge/Telegram%20Bot%20API-7.2-blue?logo=telegram)](https://core.telegram.org/bots/api)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Telegram-бот для получения актуальной погоды, прогноза на 5 дней, почасового прогноза, избранных городов и ежедневной рассылки.**  
Поддерживает русский и английский языки (определяются автоматически по вводу).  
Работает в любом чате через инлайн-режим.

---

## ✨ Возможности

- **Текущая погода** – по названию города на любом языке.
- **Прогноз на 5 дней** – с указанием дней недели, средней температурой и эмодзи.
- **Почасовой прогноз на сегодня** – разбивка по часам (команда `/daily` или кнопка).
- **Избранные города** – добавление и удаление через кнопку под погодой, быстрый доступ через меню.
- **Ежедневная рассылка** – настройка времени (от 6:00 до 12:00 с шагом 30 минут), автоматическая отправка погоды каждое утро.
- **Геолокация** – отправьте местоположение – бот определит город сам.
- **Настройка единиц измерения** – °C/м/с или °F/mph (команда `/settings`).
- **Инлайн-режим** – вызовите бота в любом чате через `@имя_бота город`.
- **Кэширование** – ответы кэшируются на 10 минут для экономии API-запросов.
- **Автоопределение языка** – русский или английский в зависимости от языка ввода.

---

## 🛠 Технологический стек

- **Python 3.9+**
- **pyTelegramBotAPI** – работа с Telegram Bot API
- **Requests** – HTTP-запросы к OpenWeatherMap
- **APScheduler** – планирование ежедневных рассылок
- **SQLite3** – хранение избранных городов и подписок
- **python-dotenv** – управление переменными окружения

## 📦 Установка и запуск

### 1. Клонировать репозиторий
git clone https://github.com/Gumilak/Telegram-Weather-Bot.git
cd Telegram-Weather-Bot

### 2. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
# или
.venv\Scripts\activate         # Windows

### 3. Установить зависимости
pip install -r requirements.txt

### 4. Создать файл `.env` и заполнить своими токенами
BOT_TOKEN=ваш_токен_бота_от_BotFather
WEATHER_API_KEY=ваш_ключ_OpenWeatherMap

- Получить токен бота: @BotFather → /newbot
- Получить API-ключ: OpenWeatherMap → зарегистрироваться и создать ключ

### 5. Запустить бота
python main.py

## 📌 Как использовать

- **Введите название города** – получите текущую погоду.
- **Нажмите кнопку «📍 Отправить местоположение»** – погода по геопозиции.
- **Нажмите «⭐ Избранное»** – выберите сохранённый город.
- **Нажмите «🔔 Подписка»** – настройте ежедневную рассылку.

**Команды:**
- `/start` – главное меню.
- `/help` – справка.
- `/settings` – выбор единиц измерения.
- `/daily [город]` – почасовой прогноз на сегодня.
- `/favorites` – список избранных.
- `/subscribe` – подписка на рассылку.
- `/unsubscribe` – отписка.

**Инлайн-режим:** в любом чате напишите `@имя_бота город` и выберите результат.
